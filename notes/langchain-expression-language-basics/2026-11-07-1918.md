# TIL: LangChain Expression Language (LCEL) Basics

LangChain Expression Language (LCEL) is a declarative syntax for chaining LangChain components (prompts, models, parsers, retrievers) using the `|` operator. It replaces legacy subclasses like `LLMChain` with a unified `Runnable` interface, enabling streaming, async execution, batching, and automatic retries without boilerplate. Every component in a chain implements `Runnable`, ensuring standardized `invoke`, `stream`, `batch`, and `astream` methods.

LCEL handles type coercion automatically: a `PromptTemplate` outputs a `PromptValue`, which the `Model` accepts; the model outputs an `AIMessage`, which an `OutputParser` converts to a string or JSON. This allows complex logic—like RAG pipelines or tool-use agents—to be defined as a single, inspectable, and debuggable object graph. It also supports advanced features like `RunnableParallel` for fan-out/fan-in, `RunnablePassthrough` for passing data through unchanged, and `RunnableLambda` for wrapping arbitrary functions.

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template("Tell me a joke about {topic}")
model = ChatOpenAI(model="gpt-4o-mini")
parser = StrOutputParser()

chain = prompt | model | parser

# Stream tokens as they generate
for chunk in chain.stream({"topic": "parallel parking"}):
    print(chunk, end="", flush=True)
```
